Taskbar Monitor portable | Windows 11 x64

Extract the entire ZIP to a writable folder and run TaskbarMonitor.exe.
Right-click the readings to open Settings or exit. If the readings are
hidden, run TaskbarMonitor.exe --settings from the extracted folder.

The application creates Data\config.json beside its executable. Keep the
Data folder when replacing the portable executable or moving the program.
Exit before replacing files. One portable instance runs per Windows session.
Installed and portable copies can run at the same time and may occupy the
same position. Choose different offsets in Settings to see both.

Windows startup registration is disabled in the portable edition.
To remove it, close the program and delete its extracted folder.
